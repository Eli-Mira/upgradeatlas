# UpgradeAtlas — premium hardware advisor (direction draft)

Status: user selected direction A; detailed visual brief pending reference-audit synthesis and confirmation. This is not implementation acceptance or product-completion evidence. Application code and database remain untouched during research.

## Correcting the product framing

The current home screen is an isolated cost form plus a synthetic catalog. That is not the specified laptop buying/upgrade product. Keep the working calculator, but move its role to the owner journey. The home page must communicate two jobs immediately: choose a laptop, or investigate upgrades for the laptop you own.

## Confirmed constraints

- Premium consumer-tech presentation with technical depth when comparing. Egypt-first, Arabic-first RTL, complete English LTR counterpart.
- React + JavaScript + Tailwind/Vite; Laravel REST API; PostgreSQL. No framework replacement.
- Prefer free/open-source components and legitimately reusable visual assets. Public viewing does not establish code, font, template or image reuse rights.
- Real product functionality, not a marketing page full of fake controls. Exact-SKU identities, explicit unknowns, field-level evidence and observed offer dates remain mandatory.
- Preserve existing cost arithmetic, validation, stale-response protection, keyboard access and automated checks.

## Proposed experience (not yet approved implementation)

1. **Home:** intentional masthead/navigation, confident Arabic headline, one useful model/search entry, premium hardware visual, and clear buying/ownership entry points. No giant calculator above the fold; no invented reviews, retailers, sale prices or popularity statistics.
2. **Find and browse:** budget/use-case controls, compact readable product imagery, exact configuration identity, honest price/source state, and visible compare actions. A useful catalog first, not endless decorative sections.
3. **Compare and detail:** aligned product silhouettes and consistent selectors, grouped specifications, sticky product identity, meaningful differences, evidence/unknown states and optional 2–4-product tray. Do not hide critical facts behind visual spectacle.
4. **Upgrade:** exact-model identification before hardware advice, documented RAM/SSD layout, clearly scoped evidence; the cost calculator supports this journey rather than defining the brand.

## Proposed visual language

- Light-first cool neutral canvas, dark ink typography, restrained cobalt controls, metallic hardware imagery. Dark mode uses the same hierarchy, not unrelated inverted sections.
- A deliberately chosen Arabic/Latin type pairing, self-hosted only after open-font license verification. Arabic glyph metrics/line heights receive a dedicated check; do not merely mirror English screenshots.
- Strong composition and product proportions, comfortable but not wasteful whitespace, clear information hierarchy, consistent shapes, and actual content-led illustration. No default blue/teal form card, gratuitous orbs, scroll hijacking or mixed component-library aesthetics.
- Motion only for state transitions and selection feedback; reduced-motion support. Component library adoption is optional, not a goal.
