# UpgradeAtlas

Egypt-first, exact-SKU laptop buying & upgrade advisor (college project).

Approved stack:
- Frontend: React + JavaScript + HTML5/CSS3 + Tailwind CSS
- Backend: PHP 8.3+ / Laravel 13
- Database: PostgreSQL 16
- Development: Git, GitHub, Docker

See `docs/PRD.md`, `docs/ARCHITECTURE.md`, and `docs/DECISIONS.md`.

Status: Phase 0/1 schema baseline complete (PostgreSQL); Phase 0b will archive the temporary Python scaffold and scaffold Laravel + React.
