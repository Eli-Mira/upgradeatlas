## What we are designing
An Egypt-first laptop decision instrument, not a gaming launch page or administrative database. The homepage creates physical desire; catalog makes configurations readable; calculator makes a cost trade-off understandable. One visual grammar, three different information densities.

### First pass -> criticism -> revised direction
The obvious black/red + outlined 3D split repeats the rejected version. A boxed viewer divides the screen into two unrelated rectangles, uniform cards hide hierarchy, and fake market statistics create false authority. Reject that plan. Revised: one integrated oversized hardware image, editorial type, honest decision paths; product-first catalog plates; analytical result as the calculator's visual anchor. No simulated record lights, four-stat proof bar, decorative serial numbers or unearned verification stamps.

## Coherent design system — original proposal
- Canvas #090A0C; recessed #0D0F12; raised #14171C; boundary #30353D; text #F2F4F7; secondary #A7ADB8. Red #E5484D is decision/action, not every title. Positive #3DD68C is comparative cost state, never unverified compatibility. Red primary buttons use dark text unless measured white-text contrast passes.
- Archivo Variable for Latin display/UI; IBM Plex Sans Arabic for Arabic. Both installed OFL licenses inspected. Deliberate compressed 800-weight Latin display via font-stretch/variable width; regular 400–500 UI. Arabic gets independent 1.45–1.6 display leading, no Latin tracking/uppercase hacks. No extra decorative font downloads.
- Desktop max content 1344px; 48px side margin at 1440, 24px at 834, 20px at 390, 16px at 320. 4px base, 8/12/16/24/32/48/72 spacing roles. Surfaces 8px; controls4px; no pills. Borders encode grouping, not enclose everything.
- Homepage display 88–104px desktop / 48px mobile; Arabic 68–76 / 38–42. Catalog display 56–64 / 36; calculator 48 / 32. Body16/1.6; compact labels13/1.4; data tabular. These are proposed optical starting points, to correct after screenshots.
- Homepage: integrated asymmetric full-width studio stage, text ~45%, product extends across remaining area and into shared negative space. Product appears within first mobile viewport; mobile crops independently below a shorter title, no shrunken desktop stage.
- Catalog: slim 216px filter rail, remaining space used by image-led product plates, 3 desktop columns only when each is readable; 2 tablet and 1 mobile. No fake live inventory count. Local synthetic sample count explicitly named. Product cards prioritize image -> model -> 3 essential attributes -> illustrative cost -> compare.
- Calculator: left editable cost composition; right analytical result area with two aligned totals, zero-based common-scale comparison bars and an honest difference sentence. Inputs not the whole experience. At mobile, example result summary precedes detailed edit form; no chart wider than viewport. Chart labels/numbers use bidi isolation; chart numerical axis can stay LTR with localized surrounding text.
