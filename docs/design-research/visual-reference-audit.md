## Per-Source Audit

### 1. 60fps.design
- **Type:** Premium design inspiration library (landing pages, OG images, components, portfolios, bento grids, interactions)
- **Business model:** Free browsing + PRO subscription ($15/mo or $150/yr) for Figma assets
- **Design value for UpgradeAtlas:** High — 400+ landing page designs and 500+ OG images provide real patterns for hero layouts, product showcases, and social preview design
- **Rights caveat:** Browsing is free. Figma components require paid license. Observing patterns ≠ licensing assets. No copy-paste of designs.
- **Relevance to hardware:** Medium-high — landing page patterns transfer well; component library useful for comparison cards

### 2. Supahero.io
- **Type:** Curated hero section library (now part of screensdesign)
- **Business model:** Free browsing; affiliate links; some premium sections
- **Design value for UpgradeAtlas:** Medium — focused exclusively on hero sections; useful for the main upgrade-atlas landing page hero
- **Rights caveat:** All designs belong to their original creators. Reference only.
- **Relevance to hardware:** Low-medium — hero sections are generic; no hardware-specific patterns

### 3. Haptikos.tech
- **Type:** Haptic technology company website (tactile feedback hardware)
- **Business model:** Commercial product site

- **Rights caveat:** Company website; no design assets available for reuse.
- **Relevance to hardware:** Paradoxically medium — it's a hardware company's site showing how to present physical tech products digitally, but no systematic design guidance.

### 4. Refero — monopo saigon
- **URL:** https://styles.refero.design/style/3e52dd36-6ab1-48c6-bc40-47ef6d33abc2
- **Style:** Editorial monochrome gallery with liquid iridescent backgrounds
- **Key tokens:**
  - Colors: Obsidian #000000, Paper #ffffff, Inkstone #181818, Felt Gray #6d6d6d
  - Typography: Roobert (display), Raleway (body)
  - Shape: 0px sharp corners on nav/text links vs. 75px full-pill buttons
  - Rhythm: 4px-based spacing
- **Design value for UpgradeAtlas:** Very high — monochrome editorial approach is ideal for laptop product photography. The chromatic/iridescent backgrounds separate product imagery from UI interface. Generous whitespace supports RTL Arabic reading flow.
- **Rights caveat:** Design patterns are described in Refero's AI-readable format. The original website (monopo.vn) holds copyright on its visual assets. Observing and learning patterns is fine; replicating the specific visual look would require permission.
- **Relevance to hardware:** Very high — editorial gallery format is purpose-built for presenting visual products (photography-first)

## Top 3 Recommended References for Premium Consumer Hardware

### #1: Refero — n8n
**URL:** https://styles.refero.design/style/8601c8ef-e1ea-4186-adb2-6f9a74caf436

**Why it fits UpgradeAtlas best:**
- **Color-stepped dark surfaces** (#0e0918 → #1a1624 → #1b1728) map directly to laptop tier comparison: base model (void) → mid-tier (elevated) → premium (deep panel)
- **Ember CTA gradient** (orange-to-red) serves as a single "best deal" / "recommended upgrade" focal point — exactly what a buying advisor needs
- **Inset orange bottom-glow on cards** mimics backlit hardware aesthetics — literal visual metaphor for computer hardware
- **Geomanist light weight at 48–54px** headlines feel restrained and premium, not aggressive
- **No drop shadows** — depth comes purely from color layering. This keeps Arabic text crisp against any background (no shadow interference with RTL text)
- **Arabic-friendly:** High-contrast surfaces, clear hierarchy, no text-over-image problems in the UI layer

**Transferable principles:**
1. Card elevation by surface color step, not shadow
2. Single warm CTA gradient against cool-dark palette for decision priority
3. Backlit-indicator visual language (inset bottom-glow) for hardware products

### #2: Refero — Basedash
**URL:** https://styles.refero.design/style/77b723ca-9583-4349-9b5e-2ef8b4fde002

**Why it fits:**
- **Pure black canvas (#000000)** with near-black cards creates maximum contrast for spec tables — critical when displaying technical details in both Arabic and English
- **White filled buttons on black** inverts standard dark-mode thinking — makes CTAs ("Compare," "Upgrade," "Buy") instantly legible and actionable
- **Serif display headline (Alpha Lyrae)** adds premium editorial quality without sacrificing technical feel
- **Tight Inter tracking (-0.03em)** gives the interface a precise, engineered quality appropriate for hardware specs
- **Violet and green accents used sparingly** — perfect for status indicators (in-stock, price-drop, upgrade-available) without overwhelming the content
- **No box shadows on cards** — keeps the interface flat and clean, letting product photography be the visual anchor

**Transferable principles:**
1. Inverted CTA (white button on black, not colored button) for maximum action visibility
2. Serif + sans-serif pairing for premium technical feel
3. Sparse chromatic accents reserved for functional status, never decoration

### #3: Refero — monopo saigon
**URL:** https://styles.refero.design/style/3e52dd36-6ab1-48c6-bc40-47ef6d33abc2

**Why it fits:**
- **Editorial monochrome gallery format** is purpose-built for product photography — laptops as objects of desire, not just specs
- **Pure B&W UI interface** with **chromatic/iridescent backgrounds** separates the interface from the product imagery — the product "floats" on atmosphere
- **Massive Roobert typography** with generous whitespace creates a premium, confident feel
- **Sharp 0px corners on navigation** vs. **75px full-pill buttons** creates hierarchy through shape contrast — useful for distinguishing navigation from primary actions
- **4px-based rhythm** provides consistent spacing that scales well for Arabic text (which often needs more vertical breathing room than Latin)
- **Monochrome discipline** ensures Arabic RTL text remains perfectly legible — no color competition between text and background

**Transferable principles:**
1. Separate product imagery from UI with chromatic background atmosphere
2. Use shape contrast (sharp nav vs. pill buttons) to establish hierarchy
3. Monochrome UI + colorful product photos = editorial premium feel
